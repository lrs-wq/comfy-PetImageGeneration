# 0007：吃饭口鼻运动与静态食盆必须由局部证据闭环

- 状态：accepted
- 日期：2026-09-03
- 负责人：Comfy Pet Pipeline
- 影响节点：`comfy.recovery.eating_full_driver_motion`、`comfy.quality.eating_muzzle_motion_gate`、`comfy.recovery.eating_static_bowl_temporal_matte`

## 背景

最新犬任务 `20260903T055308Z-7ca587d08e` 的吃饭动画有全帧轻微变化，但口鼻在碗边几乎固定。参考红色食盆框 `[66,303,205,424]` 的宽高比只有 `1.149`，实际将暖色下口鼻与食物连成一个道具组件；旧路径裁走该区域后，再抬起单张低头参考中剩余的头部像素，无法恢复被遮挡的下嘴，只会形成平直白色断口。仅审核全帧 MAE 也会把背景、身体或压缩变化误认为有效吃饭。

最新猫任务 `20260903T053156Z-51a505bf26` 则在透明化阶段丢失食盆：旧视频部分帧仍有画布证据，但语义 alpha 在源帧 `25–36` 消失，后续边缘清理继续侵蚀碗体。直接把宽泛红色引导全部设为不透明虽能保住碗，却会把引导外扩一起填成碗下白块。

## 决策

1. 犬吃饭参考没有可靠口鼻锚点，或食盆语义框宽高比低于 `1.40` 时，判定参考无法安全形变。选中 Qwen 首帧仍是身份权威，但动作几何切换到摘要锁定的完整 `81` 帧白膜；不得从单张低头参考裁除被遮挡口鼻后再臆造抬头帧，也不得退为静态姿态。
2. 吃饭 SCAIL 输出必须同时通过全帧运动与局部口鼻运动。局部门在参考口鼻走廊或完整白膜静态食盆框上追踪中央暗色口鼻组件，稳健纵向跨度至少为 `8 px`，且至少保留准备动作头部抬升的 `25%`，要求上限为 `18 px`。失败进入最多五轮逐步增强姿态信号的真实重试，best-effort 也按最弱动作轴排序。
3. 吃饭食盆是静态道具，但引导只定义搜索边界。每帧必须有有界画布 alpha 支持至少 `55%` 引导区才算可靠；可靠帧至少占 `25%` 后，以多数支持区和最高支持代表帧建立时序食盆 RGB/alpha，只在证据包络内恢复缺失帧。
4. 食盆证据核心在边缘去暗、接触阴影清理和局部 alpha 模糊中受保护；最终用 alpha `220` 审核逐帧核心保留率，最低为 `97%`。没有时序画布证据的引导像素不得被强制写为不透明。
5. 每次仓库修改后继续执行 ADR 0006 的固定自测矩阵：一个猫任务执行 `eating + grooming` 各一次，一个狗任务执行 `eating + standing` 各一次。历史媒体回放不能替代 live smoke。

## 备选方案

- 继续调大参考形变的口鼻走廊：无法生成单张低头参考中已被食盆遮住的像素，只会把白色断口移动或拉伸。
- 只提高全帧运动阈值：会把正常静态食盆、毛发抖动与真正口鼻运动混在一起，也不能定位嘴部固定。
- 用单个固定帧或整张红色引导补食盆：单帧可能正处于丢碗阶段；整引导硬填会制造碗下白块和不真实轮廓。
- 对全部 alpha 做更强膨胀/模糊：会同时填掉腿间、口鼻周围和外部自然透明间隙。

## 后果

犬参考分割异常会更早进入已有完整白膜恢复，避免不可逆的缺口形变；代价是该分支的外观更多依赖 SCAIL 将选中 Qwen 身份迁移到白膜几何。局部口鼻门增加了动作专属计算和审计字段，并可能消耗更多 SCAIL 重试，但能阻止全图噪声冒充吃饭。猫食盆恢复需要缓存一轮有界画布结果并建立时序共识，内存与处理时间略增；换来的是缺失帧可恢复、证据外区域保持透明。若可靠帧不足或核心保留失败，透明恢复失败关闭，不以无证据填充伪造食盆。
