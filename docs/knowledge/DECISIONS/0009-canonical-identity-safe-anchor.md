# 0009：Canonical 必须使用身份安全锚点

- 状态：accepted
- 日期：2026-09-04
- 负责人：项目负责人
- 部分取代：0003 中“canonical 视觉门耗尽后始终采用最低风险生成图”的部分
- 影响节点：`comfy.api.local_video`、`comfy.module.identity`、`comfy.module.pipeline`、`comfy.quality.subdued_mixed_canonical_identity_gate`、`comfy.recovery.subdued_mixed_canonical_source_matte`

## 背景

任务 `20260904T072357Z-695c863a03` 的上传猫是低饱和灰黑、灰棕和局部淡暖棕混合被毛。源图饱和暖色为 `3.4598%`，内部条纹证据为 `6` 个组件、`2.3131%` 面积；旧完成优先 canonical 却被重绘成通用橘棕虎斑，饱和暖色达到 `42.3209%`，条纹达到 `20` 个组件、`12.4528%` 面积，并出现浅色口胸、粉色鼻眼和更幼态的脸。

旧色盘门只对近纯消色差来源阻断暖色迁移。混合灰棕来源即使候选暖色饱和度剧增，只要仍保留足够黑色条纹，就可能通过。已有条纹的严重放大门还错误复用了“无条纹来源面积不高于 `1.8%`”的前置条件，使来源面积 `2.3131%` 的本任务无法进入有源放大判断。三轮生成都身份不安全后，0003 的 canonical 完成优先又把最低风险生成图传给两个动作，放大了共享身份错误。

## 决策

- `source_palette_guard_v4` 对低饱和混合被毛建立独立范围：源消色比例 `[0.30, 0.72)`、暖色不少于 `0.20`、饱和暖色不高于 `0.15`。候选饱和暖色达到 `0.30` 且比源增加至少 `0.18` 时直接失败，不再要求消色比例同时下降。
- 上述来源红粉色不高于 `0.003` 时，候选新增至少 `0.008`、相对源增加至少 `0.006` 且集中在头部的红粉特征也失败，防止暗鼻或自然琥珀眼被改成粉鼻、红眼、粉眼或幻想眼色。
- 有源条纹判断只要求来源至少 `1` 个组件且面积不少于 `0.3%`；一旦进入该模式，不再套用无源条纹 `1.8%` 面积上限。候选同时增加至少 `6` 个组件、`5.0%` 面积和 `6.5%` 暗部对比度时失败。
- 前一轮实际身份问题必须进入下一轮提示。低饱和混合被毛到达 canonical 最后一轮时，先对摘要锁定的上传身份做安全语义抠图，以纯绿结果作为 Qwen Image 1；该轮至少 `8` 步、`cfg=1.0`、`denoise=0.70`，禁用全部用户 LoRA，并明确锁定源眼色、瞳孔、鼻色、脸型和低饱和被毛。它占用既有三轮预算，不新增第四轮。
- canonical 至少有一个生成候选通过身份门时，其他透明或构图视觉问题仍可按 0003 做生成候选语义恢复。所有生成候选均未通过身份门时，终态只能使用上传身份安全抠图作为 canonical；不得把身份不安全生成图传给动作。
- 上传身份安全抠图只承担 canonical 身份锚点，不是动作输出。每个猫狗动作仍必须完成自己的五轮 Qwen 真实生成候选，并按 0003 的严格优先、完成优先策略进入 SCAIL；上传图、canonical 和兄弟动作都不能成为动作首帧或最终动画替代物。
- 相关阈值、专用输入 SHA-256、实际 denoise、LoRA 禁用状态、每轮问题和终态回退来源必须写入任务及健康审计。

## 备选方案

- 只加强提示并保留旧门：未采用。真实探针在完整重绘和移除用户 LoRA后仍生成高饱和通用虎斑，提示本身不能证明身份保持。
- 对橘化候选做全局调色：未采用。该任务同时发生脸型、眼色、鼻色、浅色口胸和条纹拓扑变化，颜色后处理无法恢复已被重画的身份结构。
- 所有 canonical 都直接使用上传抠图：未采用。大多数任务仍能得到身份合格且更适合作为动作输入的生成 canonical；专用轻重绘和上传兜底只作用于证据明确的失败路径。
- 继续让身份不安全 canonical 按完成优先进入动作：未采用。canonical 是所有动作共享的身份根，错误会同时污染两个动作，且无法由动作隔离修复。

## 后果

- 低饱和混合被毛在模型强烈橘化时会多一次源主体安全绿幕准备，但 Qwen 次数仍为三轮。
- 专用最后一轮可能比完整重绘保留更多上传姿态和摄影细节；这是身份优先的有意取舍，后续动作仍由各自动作候选改姿态。
- 极端情况下 canonical 可退回上传身份的透明抠图，因此 canonical 本身不再满足“始终是生成图”；动作和最终动画仍保持生成媒体合同。
- 对 `722` 条历史 canonical 候选审计回放，新饱和条件命中 `10` 条、涉及 `7` 个任务；除本任务旧完成优先候选外，其余均已被其他视觉门拒绝。目标生产种子真实探针通过新门：饱和暖色 `3.4598% → 3.9987%`、红粉色 `0.0032% → 0.0199%`、条纹 `6 → 7`、面积 `2.3131% → 2.4663%`。
