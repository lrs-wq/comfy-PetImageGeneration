# 0015：深色碗壁必须与食盆下方阴影分开

- 状态：accepted
- 日期：2026-09-16

## 问题与证据

犬吃饭正式复跑的原始 SCAIL 视频已让口鼻接触碗内，但透明发布删除了棕色碗壁。逐阶段提取确认，清理前碗身完整；`_remove_eating_contact_shadow` 将一块约 91×35 像素、几乎全部位于食盆范围内的碗壁识别为阴影，首帧清空约 1,680 个像素。白模食盆保护核心仅覆盖较浅范围，未保护生成碗的整个前壁。关闭这次误删后，原有边缘清理仍能保留碗身。

## 决策

- 阴影组件必须有至少 15% 像素位于检测食盆底边以下，厚度不得超过食盆高度的 25%（最低 3 像素），并将 RGB 色度上限从 44 收紧到 16。
- 食盆内部的棕色、深灰碗壁保留为实物。不因颜色深、组件宽或位于保护核心之外就清空 alpha。
- 保留原有静态碗证据恢复和保护核心，不扩大白模掩码强制不透明区域。
- 动作时序、透明媒体可读性和白模核心保留率不代表嘴碗接触或完整碗身质量，仍需检查原始视频与最终低头阶段。

## 验证

回归分别覆盖棕色碗壁、深灰碗壁、保护核心之外的棕色前景，以及真正薄的中性地面阴影；暗色尾巴继续保持。完整真实视频重导出保留碗身和原始时序。发布前执行 `verify-change.sh` 和默认猫狗四动作 live smoke。
