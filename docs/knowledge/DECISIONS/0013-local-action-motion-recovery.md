# 0013：局部动作失败先恢复真实驱动，降级和站立选优必须看动作区域

- 状态：accepted
- 日期：2026-09-15
- 补充：0003、0007

## 问题

任务 `20260915T025110Z-af16c54b00` 的犬吃饭参考形变未通过口鼻运动审核，未运行 SCAIL 就转入单图 GIF。旧降级函数按主体高度冻结下方 28%，把低头犬的真实口鼻一起冻结。100 帧可读、全图有变化仍不能代表吃饭动作有效。站立白模有明显摇尾，但原模型结果只保留弱动作；提示末尾的“只允许喘气”与前面的摇尾要求冲突，且站立未执行局部动作审核。

## 决策

犬吃饭在参考空间形变的口鼻运动不足、不可用，或垂直控制存在向上拉开单图接触区域时，保留选中 Qwen 图并重新准备一次摘要绑定的完整白模动作。新 run id 保存独立准备产物，最终清单保留原失败门和参考摘要；恢复后仍执行完整姿态、食盆、来源摘要和局部运动检查。完整白模自身失败、其他动作和运行完整性错误不通过这个分支重复尝试。

极端故障降级仍只使用已选定生成候选。吃饭降级以可识别的食盆和低头口鼻位置确定局部头颈运动，保护连通碗面与下方侧边肢体，先向食物下压再回到已观察到的原姿态。不得通过抬出单张图中被遮挡的口鼻来制造缺失像素裂口。检测不足时记录保守头部估计，不把该结果标为正常模型生成。

站立提示同时允许白模规定的摇尾和喘气，禁止冻结尾巴或用脱离主体的毛丝代替尾巴。模型最多三轮，姿态强度倍数为 1.00、1.04、1.08。对主体连通的尾部测量相对上半身的位移，消除整体平移并排除细小游离碎片；以白模动作幅度指导选优。同时检查头部有色/暗色特征和头部轮廓可用性，避免加强动作后复制白模外观。预算耗尽从真实视频中优先选择身份安全结果，再比较动作幅度，保留 best_effort 审计。视觉审核不改写完成优先合同。

v2.26.68 原图完整复跑发现，口鼻检查通过的第三轮视频仍继承了参考形变中的食盆横向裂口：食物/碗沿与口鼻粘连而被上拉，静止碗身无法补出未观察到的像素。v2.26.69 将正向垂直控制量作为生成前的接触完整性拒绝理由，复用同一个保留 Qwen 参考的完整白模恢复流程。只下压再返回原姿态不触发此项；不能通过动作阈值通过而跳过接触完整性。

## 验证与边界

- 合成局部回归覆盖低于旧冻结线的口鼻仍运动、食盆和前爪像素保持固定。
- 站立回归区分真实摇尾、静态尾巴、整幅平移与游离碎片，并拒绝金色头部变成白模头部。
- 原图离线降级 GIF 的口鼻由逐帧完全相同变为可测变化，碗前壁像素保持不变。
- 真实站立对照表明修正提示并保持原姿态强度可以恢复摇尾；过强姿态导致的白脸结果不采用。
- 上述局部检测不是通用解剖识别，也不保证所有品种的每个视频质量。完成性 live smoke 不替代原图动画检查。

发布前运行 `verify-change.sh`，发布后执行完整猫狗双动作 smoke，并额外复跑原任务输入。
