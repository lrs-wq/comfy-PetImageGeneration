# 本地四动作宠物动画提示词——完整中文版（API 2.16）

生产接口 2.16 默认使用 `pet-multipose-20260717-v2`（修订号 `multipose-v2`），采用“动作无关的统一角色基准 + 四个独立姿态模板”。它是奔跑、吃饭、喝水、趴卧全部姿态的共同基准，不是进食专用基准。其 LoRA、采样参数和渲染风格来自历史任务 `20260717T094459Z-f738613526`，但历史进食提示词只属于吃饭动作层，不会污染奔跑、喝水或趴卧。

当前代码向 Qwen 和 Wan 发送英文提示词；用户提交的中文提示词和自定义中文姿态会先由服务器本地翻译模型转为英文，同时保留中英文审计字段。本文件中的中文提示词与英文生产模板含义一致。当前版本不使用首帧像素覆盖、脸部锁定、头部锁定或上半身冻结。

## 0. 统一四姿态基准设计

v2 将提示词严格拆成三个职责层：

1. 公共角色层：只定义同一只猫的身份、毛色花纹、3D 卡通渲染风格、完整全身构图、无衣服无配饰和纯绿背景。
2. 独立动作层：奔跑、吃饭、喝水、趴卧分别定义首帧姿态、肢体关系、动作道具和 5 秒视频运动，动作之间不共享姿态语义。
3. 系统检查层：姿态重复检测、动作语义检测、完整主体检查和 v2 毛色调色板保护共同筛选候选图。

公共层必须保持动作中性：不能出现俯身、低头、进食、饮水、趴卧、奔跑、食盆、水盆或肢体坐标。吃饭和喝水可以在各自动作层使用一个碗；奔跑和趴卧的正向提示、构图规则、纠姿重试及 Wan 定位规则中不得出现 `bowl` 或任何碗互动描述。

`pet-multipose-20260717-v1` / `multipose-v1` 保留为历史兼容配置，不启用调色板保护；历史任务 ID `20260717T094459Z-f738613526` 保留为 `eating-v1`，仅用于显式复现旧进食链路。

### 公共角色基准提示词

```text
以参考图片中的猫咪为唯一身份标准，完整保留毛色和花纹位置、脸型、眼睛颜色与间距、耳形、鼻色、毛长、体型比例和尾巴特征；生成高品质萌系3D卡通角色，毛发细腻柔软，光照明亮柔和，保持自然无衣服无配饰的完整全身形象。不继承或固定参考图中的姿态、肢体坐标和构图，具体动作只由所选姿态决定。
```

### v2 身份毛色调色板保护

`identity_palette_guard=true`，策略为 `source_palette_guard_v1`。系统从上传原图的宠物主体建立主要毛色比例签名，把识别出的主毛色和明确缺失的高风险颜色动态追加到身份图与姿态图提示词，并对每轮候选图再次检查。新增显著橙棕色、把黑白猫改成暖色猫等高置信度毛色漂移会被拒绝；系统继续使用降低 LoRA 影响的重试候选。

吃饭和喝水的姿态检查会排除主体下部的碗与食物区域，避免道具颜色被当成毛色；奔跑和趴卧没有道具豁免。无法可靠分割主体时，保护状态记为“不可用”并保留其他检查，不会把未检查结果标记为已保持毛色。

### 统一基准验收标准

- 身份：脸型、眼睛、耳朵、鼻色、毛长、体型、尾巴和可见花纹位置能够对应上传原图。
- 毛色：v2 调色板检查可用时不得新增高置信度主毛色；毛色漂移候选不能作为图片抠图失败时的原图回退。
- 风格：四张首帧共用同一套高品质萌系 3D 角色设计、毛发质感和光照语言，不导入衣服或配饰。
- 构图：每张都只含一只完整全身宠物，四肢、四爪、双耳和完整尾巴可读，主体四周保留绿幕余量。
- 动作：四种姿态在缩略图尺寸下也能直接区分，不能只是同一坐姿的平移、缩放或轻微重绘。
- 道具：奔跑/趴卧为零道具；吃饭/喝水各自恰好一个与前爪接触或轻微重叠的浅碗，碗不得遮挡或替代肢体。

## 1. 模板变量

- `{用户提示词}`：接口请求中的 `prompt`，控制视频情绪和辅助动作。
- `{动作描述}`：动作名称、首帧姿态和视频动作的组合描述。
- `{首帧专项规则}`：奔跑、吃饭、喝水或趴卧对应的首帧规则。
- `{视频专项规则}`：奔跑、吃饭、喝水或趴卧对应的视频规则。
- `{动作接触规则}`：按动作动态生成；吃饭/喝水允许一个动作必需的碗接触绿幕，奔跑/趴卧则明确禁止道具。
- `{动作道具定位规则}`：按动作动态生成；吃饭/喝水同时稳定角色与唯一碗，奔跑/趴卧只稳定角色并明确禁止道具。

## 8. 各动作视频专项规则

### 奔跑

```text
生成清晰、中等速度的猫科原地循环奔跑。后腿依次收拢和蹬伸，脊柱轻微屈伸，前腿依次前探和落地，每只脚掌都回到躯干下方。四条腿必须始终彼此分离并连接正确；承重脚掌不能滑动。允许身体小幅协调起伏和尾巴自然反向摆动，整体中心保持在相近位置，不能向前移动或长时间腾空，并在接近起始触地相位时结束以形成平滑循环。
```

### 吃饭

```text
食盆必须完全固定。使用轻微、协调的颈部、口鼻和下颌动作，并配合胸部和身体的细微呼吸，形成克制自然的循环进食。头部和脸部必须作为一个完整解剖结构运动；不能拉伸嘴巴或改变脸颊、眼睛和鼻子形状。猫粮不能飞出、突然出现或消失。
```

### 喝水

```text
水盆必须完全固定。生成克制的舔水动作：一小段粉色舌尖自然伸出和收回，口鼻与颈部只做极小幅度的协调运动，并配合细微呼吸和局部柔和水面波纹。脸部必须保持为一个完整解剖结构。不能出现飞溅、口水、透明或拉长的舌头，也不能出现连续水线。
```

### 趴卧

```text
保持放松趴卧姿态。生成胸腹部缓慢细微呼吸、小幅自然协调的头部和耳朵响应，以及一次柔和的尾尖动作。整个身体应当对呼吸产生轻柔联动，不能冻结上半身；同时避免整体滑动或比例漂移。
```

## 12. 系统自动纠姿提示词

用户不需要填写以下内容。第 1 次姿态不合格时，第 2 次会自动附加：

```text
姿态纠正重试：上一次结果复制了标准角色参考图的姿势，因此被拒绝。现在必须生成清楚不同、符合当前动作的完整全身轮廓。保留身份和渲染风格，但不能保留上一次身体姿势、肢体位置、构图或主体比例。
```

第 3 次会按道具边界继续附加。

吃饭/喝水：

```text
最终姿态纠正重试：当前动作必须在缩略图尺寸下也能一眼辨认。充分改变躯干角度、腿部位置、头部高度、尾巴位置以及当前动作必需的唯一碗互动，使它与中性坐姿或站姿明显不同。
```

奔跑/趴卧：

```text
最终姿态纠正重试：当前动作必须在缩略图尺寸下也能一眼辨认。充分改变躯干角度、腿部位置、头部高度和尾巴位置，使它与中性坐姿或站姿明显不同。不得出现任何道具。
```
