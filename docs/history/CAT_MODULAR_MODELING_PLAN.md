# 猫咪模块化建模计划

## 目标

将当前“整只猫一次性图生 3D”的流程，调整为“拆解生成、统一装配”的模块化建模流程。核心目标是降低 Hunyuan3D 单次生成时在胡须、眼睛、嘴鼻、耳朵、脚垫、毛发等细节上的错误概率，并让后续局部优化可以只改某个部件，不必每次重跑整只猫。

最终输出应包含：

- 一份完整猫咪主模型。
- 可独立替换的眼睛、鼻子、耳朵、脚垫、尾巴、毛发、胡须等部件。
- Blender 组装工程文件。
- 可导出的展示版 GLB/FBX/OBJ。
- 可用于后续动画或视频的基础 rig/骨架预留方案。

## 总体思路

不再把参考图中的所有细节都交给 3D 生成模型一次性理解，而是拆成三层：

1. **主体层**
   只负责身体、头部、四肢、尾巴的大形体，不保留胡须、眼睛高光、毛边碎线等容易误建模的细节。

2. **部件层**
   眼睛、鼻子、耳朵、脚垫、爪子、胡须、领结/眼镜等作为独立 mesh 或曲线对象生成。

3. **材质与毛发层**
   花纹、毛流、胸口围脖、耳缘毛、身体短毛由贴图、Blender 曲线毛发、粒子毛发或 hair cards 单独处理。

这样可以把“模型生成问题”拆成“主体比例问题”和“局部部件质量问题”，更容易定位和修复。

## 模块拆分

### 1. 主体 Body Shell

范围：

- 躯干
- 头部基础形体
- 四肢基础形体
- 尾巴基础形体
- 胸口围脖的大体积

处理方式：

- 输入参考图需要先清理 alpha、胡须、眼睛高光细线、嘴边碎线。
- 使用 Hunyuan3D / StableFast3D 等生成基础 mesh。
- 只追求轮廓、比例、姿态和体积，不要求眼睛和胡须精确。
- 输出一个干净的 base body mesh。

验收标准：

- 主体没有明显碎片。
- 嘴边没有胡须状浮动面片。
- 头、身体、脚、尾巴比例接近参考图。
- mesh 连通性稳定，适合后续装配部件。

### 2. 眼睛 Eyes

范围：

- 左右眼球
- 虹膜
- 瞳孔
- 高光
- 眼睑边缘

处理方式：

- 不依赖 3D 生成模型自动生成眼睛。
- 在 Blender 中使用标准球体或椭球体建模。
- 虹膜和瞳孔使用独立贴图或程序材质。
- 高光使用小型透明/白色表面或 shader 高光。
- 眼睛作为左右两个独立对象，绑定到头部 anchor 点。

验收标准：

- 眼睛对称。
- 瞳孔清晰。
- 没有黑洞、贴图破碎或被毛发遮挡。
- 可单独替换眼睛颜色和高光大小。

### 3. 鼻子与嘴部 Nose / Muzzle

范围：

- 粉色鼻头
- 嘴部线条
- 鼻梁过渡
- 嘴垫区域

处理方式：

- 鼻子使用独立小 mesh。
- 嘴垫使用浅色椭球/局部表面贴合主体。
- 嘴线用细曲线对象或贴图绘制，不让 3D 生成模型从参考图里自动建出来。
- 胡须孔可以用小黑点贴图或浅凹陷表达。

验收标准：

- 鼻子干净，无黑块。
- 嘴部不出现碎面片。
- 鼻头与脸部贴合自然。
- 后续可单独调整鼻子颜色、大小和位置。

### 4. 耳朵 Ears

范围：

- 左右耳外形
- 耳内粉色区域
- 耳缘绒毛

处理方式：

- 基础耳朵可以来自主体 mesh。
- 如果主体耳朵变形，则用独立耳朵 mesh 替换。
- 耳内材质使用单独粉色材质或贴图。
- 耳缘毛使用 Blender 曲线毛发，密度低、长度短。

验收标准：

- 耳朵轮廓尖而稳定。
- 耳内颜色自然。
- 耳缘毛不炸、不穿模。
- 左右耳可以单独微调位置和旋转。

### 5. 脚掌与脚垫 Paws / Paw Pads

范围：

- 四只脚基础形体
- 脚趾分割
- 粉色/深色脚垫
- 小爪子

处理方式：

- 主体只生成脚的大形。
- 脚垫使用独立扁椭球 mesh 或贴片 mesh。
- 脚趾分割可用浅凹线或局部曲线。
- 爪子可作为可选独立小 mesh。

验收标准：

- 脚垫位置正确。
- 脚垫不漂浮、不穿出过多。
- 四只脚可根据姿态单独调整。
- 近景展示时脚掌有细节。

### 6. 尾巴 Tail

范围：

- 尾巴基础 mesh
- 环状花纹
- 尾端毛发

处理方式：

- 如果主体尾巴生成稳定，则保留。
- 如果尾巴粗细或弯曲错误，则独立生成/建模尾巴，再与身体连接。
- 花纹使用贴图或程序环纹。
- 尾巴毛发使用短毛粒子层或 hair cards。

验收标准：

- 尾巴曲线自然。
- 花纹沿尾巴方向连续。
- 尾巴根部连接自然。
- 转动查看时不露缝。

### 7. 毛发 Fur

范围：

- 身体短毛
- 胸口长围脖
- 脸颊毛
- 耳缘毛
- 尾巴毛

处理方式：

- 不让图生 3D 模型直接生成细毛结构。
- 使用 Blender 粒子毛发或曲线毛发作为渲染层。
- 身体用短密底毛。
- 胸口、脸颊、耳缘单独使用局部长毛 mask。
- 毛色尽量跟随原贴图，避免统一白毛覆盖花纹。

验收标准：

- 毛发贴服，不像刷子或刺。
- 花纹仍可见。
- 胸口有布偶猫长毛体积。
- 眼睛、鼻子、嘴部不被毛发糊住。

### 8. 胡须 Whiskers

范围：

- 左右胡须
- 胡须孔

处理方式：

- 输入图中先淡化或去除胡须，避免 ShapeGen 把胡须生成成碎片。
- 在 Blender 中使用细曲线对象单独生成胡须。
- 每侧 3 到 5 根，使用 Bezier 曲线。
- 胡须根部绑定到嘴垫 anchor 点。

验收标准：

- 胡须是细线，不是块状 mesh。
- 胡须从嘴垫两侧自然伸出。
- 转动视角时不穿脸、不漂浮。
- 可单独开关显示。

### 9. 配饰 Accessories

范围：

- 眼镜
- 领结
- 项圈
- 衣服

处理方式：

- 配饰全部独立建模或使用现成基础模型。
- 不与主体 mesh 合并，保持可替换。
- 通过 anchor 点装配到头部、脖子或身体。

验收标准：

- 配饰不穿模。
- 可单独隐藏或替换。
- 不影响毛发层。

## 拼接与装配规范

### 坐标规范

- 主体模型作为坐标基准。
- 猫面朝 -X 或统一指定方向。
- Z 轴为高度。
- 所有部件都以主体 bounding box 的归一化坐标定位。

### Anchor 点

建议建立以下 anchor：

- `head_center`
- `left_eye`
- `right_eye`
- `nose_tip`
- `left_muzzle`
- `right_muzzle`
- `left_ear_base`
- `right_ear_base`
- `front_left_paw`
- `front_right_paw`
- `back_left_paw`
- `back_right_paw`
- `tail_root`
- `chest_fur_area`

每个独立部件都通过 anchor 装配，而不是靠手动猜坐标。

## 技术路线

### 阶段 1：参考图清理

目标：

- 去透明边缘。
- 去胡须线。
- 去嘴边细碎线。
- 保留主体比例和花纹。

输出：

- 干净 alpha 图。
- 弱胡须/无胡须图。
- 用于 TexGen 的彩色参考图。

### 阶段 2：主体生成

目标：

- 用清理后的图生成基础 body shell。
- 不追求眼睛、鼻子、胡须等局部细节。

输出：

- `body_raw.glb`
- `body_clean.glb`
- 主体预览图。

### 阶段 3：主体修复

目标：

- 删除明显 floating fragments。
- 平滑不自然的碎边。
- 修复嘴鼻区域不要出现大洞。

注意：

- 不建议自动删除大面积嘴鼻面片。
- 对脸部区域优先使用局部重建或单独部件覆盖。

### 阶段 4：独立部件建模

优先级：

1. 眼睛
2. 鼻子
3. 嘴垫
4. 胡须
5. 耳朵
6. 脚垫
7. 尾巴细化
8. 配饰

每个部件都要单独导出，并记录 anchor 信息。

### 阶段 5：材质与贴图

目标：

- 主体使用 TexGen 生成大面积花纹。
- 眼睛、鼻子、脚垫、耳内使用独立材质。
- 毛发颜色跟随主体贴图。

输出：

- 主体贴图。
- 部件材质。
- 毛发 mask。

### 阶段 6：Blender 装配

目标：

- 导入主体。
- 根据 anchor 放置各个部件。
- 添加毛发层。
- 添加灯光和相机。
- 输出最终 `.blend` 和预览图。

### 阶段 7：导出与展示

输出分两类：

- **渲染展示版**：保留 Blender 毛发，适合图片/视频。
- **实时展示版**：转成 GLB/FBX，毛发需要转换为 hair cards 或简化 mesh。

## 推荐 MVP

第一版不要一次拆太多，先做最影响观感的几个模块：

1. 主体 body shell
2. 独立眼睛
3. 独立鼻子/嘴垫
4. 独立胡须曲线
5. Blender 毛发层

MVP 完成后，再补脚垫、耳缘毛、尾巴花纹和配饰。

## 风险与解决方案

### 风险 1：主体比例仍然偏胖

解决：

- 在生成前调整参考图比例。
- 或在 Blender 中对 body shell 做局部缩放。
- 保持头、胸、身体分区控制。

### 风险 2：眼睛贴不到正确位置

解决：

- 建立眼睛 anchor。
- 使用正面相机投影辅助定位。
- 眼睛独立对象可反复微调。

### 风险 3：胡须再次变成块状

解决：

- 输入图中不保留清晰胡须线。
- 胡须只在 Blender 中用曲线生成。
- 不让 ShapeGen/TexGen 负责胡须结构。

### 风险 4：毛发不像猫毛

解决：

- 毛发不能统一白色。
- 必须跟随 UV 贴图颜色。
- 使用短密底毛 + 局部长毛。
- 眼鼻嘴区域用 mask 排除毛发。

### 风险 5：导出 GLB 后毛发消失

解决：

- 渲染版保留 `.blend`。
- 实时版单独做 hair cards 或 mesh fur。
- 文档中明确区分展示版和实时版。

## 验收标准

完整装配版本应满足：

- 正面、侧面、背面没有明显黑洞。
- 眼睛清晰可见，不是贴图糊点。
- 鼻子和嘴垫干净。
- 胡须是细线，不是块状碎片。
- 身体花纹清晰。
- 毛发有猫毛质感，不像刷毛或塑料刺。
- 主要部件可单独替换或隐藏。
- `.blend` 可继续编辑。
- 展示图和导出模型能稳定打开。

## 后续开发顺序

1. 先建立 `cat_modular_model` 工作目录。
2. 固定主体生成输入图规范。
3. 建立 anchor 计算脚本。
4. 制作眼睛模块。
5. 制作鼻子/嘴垫模块。
6. 制作胡须曲线模块。
7. 将现有 Blender 毛发脚本改为读取模块化主体。
8. 完成第一版装配 `.blend`。
9. 输出正面、侧面、背面预览图。
10. 再加入脚垫、耳朵细化和配饰。

## 结论

模块化建模比整只猫一次性生成更适合当前需求。整猫生成适合快速获得主体轮廓，但不适合处理眼睛、胡须、嘴鼻、脚垫和毛发这种高精度细节。后续应把 Hunyuan3D / TexGen 作为“主体生成器”，把 Blender 作为“部件装配与毛发渲染器”，用独立部件解决局部质量问题。
