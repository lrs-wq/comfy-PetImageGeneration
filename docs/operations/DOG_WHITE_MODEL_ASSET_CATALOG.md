## 测试平台启用状态

生产/API 自动路由仍保持关闭，`neutral_dog` 继续作为现有犬类回退类别。测试平台通过已有的 `subject_profile` 字段显式选择以下配置，不新增或改变生产 API 参数：

- 中型犬：`dog_medium_white_model_test_v1`，动作 `eating / standing`，资产别名为 `neutral_dog`；
- 小型犬：`dog_small_white_model_test_v1`，动作 `eating / drinking / running / sleeping / toileting / standing`，使用 `small_dog/runtime-v2`。

小型犬六条测试动作已经完成：中心正方形裁剪、`512×512 / 81 帧 / 16 FPS`、移除音轨、首尾闭环检查、透明几何参考与 SHA-256 冻结。喝水源片不是天然闭环，因此固定使用前半段低头正放与倒放抬头组成 `81` 帧闭环；睡觉首帧选择哈欠前的闭眼蜷卧帧，完整驱动仍保留自然哈欠动作。上传宠物图仍是身份、犬种、体型、脸部、毛色、花纹和毛长的唯一外观标准；白膜只提供动作几何、动作道具和时序。

小型犬动作进入生产自动路由前仍必须完成：

1. 分别完成六动作真实上传图端到端验收；
2. 验证主体完整性、食盆/饮水接触、四足步态、睡姿、托盘和动作语义；
3. 确认动作专用身份颜色/条纹审计和最终视频质量；
4. 上线显式形态路由后，才允许将默认小型犬上传任务切换到该资产组。

在完成上述步骤前，禁止根据文件夹名称或自动分类改变现有生产任务路由。测试平台选择中型犬或小型犬时，以该显式选择为准；分类结果只保留作审计，不得静默改回默认类别。
